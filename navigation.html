Navigation and discovery

Guide shoppers with OBJECT INDEX, collection navigation, search and filters.

On this page

  • Configure OBJECT INDEX
  • Build collection paths
  • Set up search and filters
  • Finish footer navigation

Configure OBJECT INDEX

  1. Prepare the links in a Shopify menu. Include the core collections shoppers need. Put care, delivery and returns into a separate menu if you want a shorter primary list.
  2. In the editor, open Header and select the Navigation menu. Turn on Enable OBJECT Index and optionally select the Secondary index menu.
  3. Choose a Fallback preview image. Add a Collection preview block to override the image for a specific linked collection. Select the collection and a Preview image. The header supports up to eight override blocks.
  4. Preview desktop and mobile. Open the Index, expand any nested items and follow a link. On desktop, use Tab to reach a collection link and Escape to dismiss the open Index.

With an empty primary menu the Index shows a Shop link. The enhanced image panel appears on larger, sufficiently tall viewports. The menu still links to products and collections on smaller screens.

Turn off Enable OBJECT Index to use the standard header navigation for the selected look.

Build collection paths

On a collection template, open Collection and select an optional Collection navigation menu. Use links to closely related collections to help shoppers move between them. This menu and the header menu can use different Shopify menus.

Set a title, description and suitable collection image in Shopify. Preview a filled collection, a sold-out product and an empty result on mobile.

Set up search and filters

In the Search section, check Show product suggestions as customers type and choose a Maximum product suggestions count. Search can still show its full results page.

Configure storefront filters such as availability, price and relevant product options using Shopify Search & Discovery. The available refinements depend on your catalogue and store configuration. Apply multiple filters, sort the results and clear the filters on both collection and search pages. Shopify filter setup

Finish footer navigation

In Footer, set the Shop menu and Service and policy menu and add accurate delivery, care and returns information. Enable Show country and language selectors if relevant, then verify they appear for configured choices. Review Show newsletter signup and Show Follow on Shop based on the services enabled for your store.
