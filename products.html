Products and purchasing

Set up variants, product information, media and purchase controls.

On this page

  • Set up products and variants
  • Check the product gallery
  • Add materials, dimensions and policies
  • Choose where to show Quick Buy
  • Test Sticky Purchase
  • Check cart and checkout setup

Set up products and variants

  1. In Shopify Products, enter the title, description and media. Set each variant’s option values, price, compare-at price when applicable, and inventory. Enable the product for the Online Store.
  2. Assign an image to each variant where the finish or size should change the photograph. Add descriptive alt text to product images and inspect unusual crops at mobile width.
  3. In the Product section, keep Price, Variant picker and Buy buttons for a configurable product. Check available and sold-out selections. A variant link supplied by Shopify can preselect the intended choice.

Try a simple single-variant item, an item with multiple finishes and a sold-out choice. For example, open a listing with Matte and Gloss finishes and confirm the selected finish, photo, price and availability all agree before adding it. Shopify product media guide

Check the product gallery

Use the previous and next controls or the media thumbnails to browse. When an image is active, Inspect photo opens image zoom. Use Escape to close it. Videos and models have their own controls.

When two variants have the same explicitly assigned image, choosing either should restore that image after you browse away. If both variants have only the same product fallback, the gallery can keep the slide you were already viewing. Test both cases when they occur in your catalogue.

Use Animate gallery changes in the product section to control gallery animation. Reduced-motion preferences take precedence.

Add materials, dimensions and policies

Use Product fact for a short label and value. The standard template includes Material and Dimensions blocks. Use Information disclosure for care or delivery details, and attach a store policy page using Linked page when useful.

For per-product content, create and populate a product metafield in the custom namespace. For example, use custom.material and enter only material under Custom metafield key. Leave the block’s typed Value empty so the metafield is used. For the information block, typed Content takes precedence over its metafield.

Leave empty information blocks in the editor only if you intend to populate them. The storefront can hide them when no content or page is assigned. If you use an older template with Use legacy product layout, add the core product blocks in a duplicate before turning that option off.

Choose where to show Quick Buy

Enable Show Quick Buy in a collection, Featured collection or Shoppable Editorial Scene. Direct add requires an available product with one default variant, standard quantity rules and no gift-card or selling-plan requirements or choices. A product needing configuration can still lead to its full product page.

Test an eligible item on a phone. Add it once and confirm one cart line with the intended quantity. Test a multi-option item separately and confirm shoppers can reach its full purchase form.

Test Sticky Purchase

In the main Product section, enable Show sticky purchase on mobile. Scroll below the buy form while you are still within the product section. The mobile bar can show price and availability. It sends shoppers to the main options when a selection, selling plan or gift-card recipient needs attention.

Choose a variant, check the bar reflects the selection, and confirm that the item added matches the chosen variant and quantity. Repeat with a sold-out choice. If the bar never appears, check it on a narrow phone preview and confirm the main Buy buttons block exists.

Check cart and checkout setup

  1. Add an available item in the preview. Compare the quantity and totals in the drawer and the full cart. Update the quantity, then remove the item.
  2. Where enabled, check order notes, discounts, selling plans, pickup locations and gift-card recipient fields with eligible test products. Shopify controls the relevant product, payment and location configuration.
  3. Check Show accelerated checkout buttons and Show Shop Pay Installments where relevant. Provider eligibility controls availability.
  4. Repeat in each market and language you plan to use. Verify labels and local price formatting, and stop before payment while testing a preview.
