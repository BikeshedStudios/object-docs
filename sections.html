Build your storefront

Arrange sections in the theme editor and choose which products and stories to feature.

Work in the theme editor

Open the draft theme and choose the template you intend to edit. Use Add section or open a section and choose Add block. Move sections and blocks to change the order, configure each item, then save and preview. An edit to a shared template can affect all products or collections that use it.

Some sections are available only on certain templates. If an item is missing from the picker, check the selected template. An editor placeholder may disappear from the storefront until a product, collection or image is assigned.

Create the homepage opening

Open Photographic opening on the homepage. Set the heading, introduction and Editorial photograph. Choose a descriptive Button label and Button link. Review the photograph and caption at mobile and desktop widths.

Use the Identifier, Headline, Supporting text, Link label and Link destination settings in the opening for its accompanying editorial band. Use Studio statement on the homepage for a short closing note.

Feature collections and products

Featured collection
Select a collection and its Maximum products. Choose whether to show Quick Buy.
Collection spotlight
Add up to six Collection blocks and choose images and short summaries. Preview the interactive image changes if enabled.
Collection discovery
Add up to four Collection blocks to present multiple collection destinations.
Featured product
Choose a product and Media position. Use the product’s own blocks for price, variant selection and purchase. It is available on home, product, collection and page templates.

On product templates, Related objects can use Shopify recommendations or a manual collection. Complementary products is a separate product block. Configure Shopify recommendations and test the result with a real product.

Tell a story with media

For a still image paired with a linked object, add Material and object story and select a Story photograph and optional Featured object.

For a flexible editorial layout, add Media Story. Select an Image or Shopify-hosted video. Set Media position, the Image and player shape, and the text layout. Add overline, heading, text and link blocks in the order you want.

For a video, choose a Video poster and add a URL for a same-origin or cross-origin-enabled WebVTT captions file and a captions language code where relevant. Animate text entrance controls the copy animation. Check playback, captions and reduced-motion behavior in the storefront preview.

Make a Shoppable Editorial Scene

  1. Add Shoppable Editorial Scene and select a Scene image with publication rights. Add a heading and short introduction.
  2. Add up to six Product hotspot blocks and select one product in each. Set Position from left and Position from top to put the marker on the object.
  3. Choose the Mobile layout. Test every marker and the matching product detail by touch and keyboard. Link to purchase options links to the first available variant when there is one.
  4. Enable Show Quick Buy if it suits the scene’s products. Check Quick Buy eligibility before expecting an Add to cart action.
